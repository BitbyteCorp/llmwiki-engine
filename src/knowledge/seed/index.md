# 지식 색인

이 색인은 지식 저장소 전체의 유일한 최상위 진입점이며 도메인 허브와 공용 노트로 안내한다. 현재 정리된 지식 노트가 없으므로 연결 항목은 비어 있다.

## 도메인 허브

실제로 생성한 `wiki/<domain>/index.md` 허브를 연결한다. 도메인 내부 노트의 진입점은 각 허브에서 관리한다.

## 공용 진입점

`wiki/concepts/`의 개념·용어와 `wiki/entities/`의 사람·조직·도구·제품 중 실제로 존재하며 여러 도메인의 탐색에 도움이 되는 정본을 연결한다.

## 날짜별 정리

실제로 작성된 `journal/YYYY-MM-DD.md` 일기 중 탐색에 도움이 되는 정리만 연결한다. 개별 변경의 세부 이력은 git 커밋 이력에서 확인한다.
